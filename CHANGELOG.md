# Changelog

## 0.1.0 (2026-11-18)

- Initial release: GMI Cloud text-to-speech provider for AnythingLLM
  (Inworld Realtime TTS, MiniMax speech synthesis, Chatterbox), family-aware
  request mapping through GMI Cloud's multimodal request queue, synchronous
  and queued response resolution, and long-text chunking into a single WAV.
- Verified with 31 checks: 18 offline behavior checks, 5 live checks, and
  8 registry and edge checks.
